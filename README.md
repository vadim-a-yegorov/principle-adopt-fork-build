# scan_reuse_adopt

Search existing solutions before writing new code. Adopt, fork, or build.

## Install

Copy `SKILL.md` into your agent's skills directory.

## Use

Ask the agent to check for an existing solution before starting a new implementation. The agent searches GitHub first, then secondary platforms, and returns one recommendation: adopt, fork, or build.

## Rule

Build only when existing options are stale, narrow, or structurally mismatched. The best code is the code never written.
